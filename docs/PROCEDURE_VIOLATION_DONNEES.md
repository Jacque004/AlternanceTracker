# Que faire en cas de violation de données

Procédure du responsable d’AlternanceTracker. Une violation est un accès, une perte ou une modification de données personnelles qui ne devait pas avoir lieu (compte exposé, clé divulguée, bucket ouvert, e-mail parti au mauvais destinataire).

## Dans les premières heures

1. Couper l’accès en cause : révoquer la clé (Supabase, Google, OpenAI, Resend), changer le mot de passe du compte prestataire, retirer un administrateur si besoin.
2. Noter l’heure de découverte, ce qui s’est passé, les catégories de données et le nombre de personnes concernées, autant qu’on puisse le savoir.
3. Empêcher que cela continue (règle d’accès, fonction, sauvegarde).

## Prévenir

- **CNIL** : si la violation présente un risque pour les personnes, la notifier dans les 72 heures après en avoir pris connaissance, sur [cnil.fr](https://www.cnil.fr). Si la notification est plus tardive, expliquer pourquoi.
- **Personnes concernées** : les prévenir si le risque est élevé, dans un langage clair : ce qui s’est passé, les données concernées, ce qu’elles peuvent faire, le contact jacquesloemba@outlook.fr.
- Garder une copie de la notification et des e-mails envoyés.

## Après

Corriger la cause, vérifier que les autres comptes et clés ne sont pas touchés, et compléter le registre si le traitement a changé.
