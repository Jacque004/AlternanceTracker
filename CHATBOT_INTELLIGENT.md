### 3. 🤖 **Prompt système ultra-avancé**

**2500+ mots de prompt système** qui transforme Gemini en véritable coach professionnel :

- 🧠 **Analyse contextuelle** : Comprend la situation globale
- 💡 **Raisonnement stratégique** : Identifie les patterns et propose des stratégies
- 🎯 **Personnalisation poussée** : Chaque réponse est unique
- 📊 **Data-driven** : Base ses conseils sur les vraies données
- 🔮 **Anticipation** : Détecte les problèmes avant qu'ils ne s'aggravent

### 4. 💬 **Suggestions intelligentes**

**Avant :**
```
- "Comment créer une candidature ?"
- "Comment générer une lettre ?"
- (Toujours les mêmes pour tout le monde)
```

**Maintenant (exemples réels) :**
```
Utilisateur avec 0 candidatures :
→ "Comment créer ma première candidature ?"

Utilisateur avec 15 jours d'inactivité :
→ "Ça fait 15 jours sans candidature, comment me remotiver ?"

Utilisateur avec 20+ refus :
```

Les suggestions **s'adaptent automatiquement** au profil !

## 🚀 EXEMPLES DE RÉPONSES INTELLIGENTES

### Exemple 1 : Nouvel utilisateur (0 candidatures)

**Question :** "Comment commencer ?"

**Réponse intelligente :**
```
Hey ! Je vois que tu n'as pas encore créé de candidature, c'est normal, tout le monde 
commence quelque part ! 🎯

Voici ta roadmap :
1. Va dans "Candidatures" → "Nouvelle candidature"
2. Ajoute une entreprise qui t'intéresse (LinkedIn, Indeed, etc.)
3. Utilise le générateur IA pour créer ta lettre de motivation
4. Fixe-toi un objectif : 5 candidatures cette semaine !

La clé c'est la régularité. 5-10 candidatures/semaine = alternance trouvée en 2-3 mois 
en moyenne. Tu vas y arriver ! 💪
```

### Exemple 2 : Utilisateur avec 23 candidatures, 2 réponses (9%)

**Question :** "Pourquoi je n'ai presque aucune réponse ?"

**Réponse intelligente :**
```
Je comprends ta frustration ! 23 candidatures avec seulement 2 réponses (9% de taux), 
c'est en-dessous de la moyenne (15-20%). Mais c'est réparable ! 🔧

Diagnostic probable :
• Ton CV n'est peut-être pas optimisé pour les ATS (logiciels de recrutement)
• Tes candidatures ne sont peut-être pas assez ciblées

Actions immédiates :
1. Va dans "Préparer" → "Analyse de CV" pour scorer ton CV
2. Personnalise davantage tes lettres (utilise le générateur IA)
3. Cible des entreprises plus alignées avec ton profil

Objectif cette semaine : 3 candidatures ULTRA-personnalisées plutôt que 10 génériques. 
1 bonne candidature > 5 moyennes ! ✨
```

### Exemple 3 : Utilisateur avec 5 entretiens, 0 acceptation

**Question :** "J'ai eu 5 entretiens mais aucune offre..."

**Réponse intelligente :**
```
Ok, analyse : 5 entretiens = ton profil plaît aux recruteurs ! ✅
Mais 0 acceptation = problème de préparation aux entretiens, pas de ton CV. 🎯

Ce qu'on va faire :
1. Après chaque entretien, note ce qui a été demandé (dans les notes de candidature)
2. Identifie les questions qui t'ont piégé
3. Prépare des exemples concrets de projets/réalisations
4. Travaille ton pitch de présentation (30 sec max)

Le prochain entretien, tu vas le CARTONNER ! 💪 
Veux-tu des conseils spécifiques sur la préparation d'entretien ?
```

## 🔥 CAPACITÉS AVANCÉES

### 1. **Détection automatique de problèmes**

Le chatbot identifie automatiquement :
- ⚠️ Taux de réponse trop faible (< 10%)
- ⚠️ Pas de candidature depuis > 7 jours (démotivation)
- ⚠️ Beaucoup d'entretiens mais 0 acceptation (problème de préparation)
- ⚠️ Volume trop faible (< 5 candidatures)
- ⚠️ Trop de refus (> 80%)

### 2. **Analyse de patterns**

- 📊 Compare aux moyennes du marché
- 📈 Identifie les tendances (amélioration ou dégradation)
- 🎯 Suggère des actions correctives spécifiques

### 3. **Coach motivationnel**

- 💪 Encourage quand l'utilisateur est découragé
- 🎉 Célèbre les petites victoires
- 🔥 Remotivé après période d'inactivité
- 🎯 Fixe des objectifs réalistes et atteignables

### 4. **Conseils actionnables**

Chaque réponse contient **au moins une action concrète** :
- ✅ "Va dans X section"
- ✅ "Fixe-toi cet objectif"
- ✅ "Teste cette stratégie"
- ✅ "Analyse ce point"

Jamais de conseils vagues !
